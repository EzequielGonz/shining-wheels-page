# Shining Wheels - Premium Car Detailing Miami

Sitio web premium para empresa de lavados y detailing de autos en Miami.

## Características

- **Header simétrico** con logo centrado como punto focal
- **Hero section** con video de fondo y CTAs
- **Sección de características alternadas** estilo Obsessed Garage
- Diseño responsive y premium

## Tecnologías

- React 18
- Vite
- CSS puro

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Assets necesarios

Necesitarás agregar:
- Video hero: `/public/hero-video.mp4`
- Imágenes para las secciones de características (puedes reemplazar los placeholders)
